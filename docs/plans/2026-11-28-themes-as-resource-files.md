# Plan — Themes as plain JSON resource files (ADR 0037)

Replace theme plugins (`kind = ["theme"]`, `.kkp` packages, `plugins/theme-default`, `templates/theme`) with plain `.json` theme resource files, a bundled gallery of popular developer themes with preview thumbnails in Settings → Appearance, and direct `.json` file import stored in client settings. Also remove `kumikit.threads` from `kumikit/registry` since it is now bundled.

## Steps

- [x] **1. ADR and specs.** Write [ADR 0037](../decisions/0037-themes-as-resource-files.md) and update `08-themes.md`, `07-ui-plugins.md`, `10-distribution.md`, `01-architecture.md`, `AGENTS.md`, and `docs/decisions/README.md`. Withdraw `kumikit.threads` from `../kumikit-registry` (`yanked = true` on `plugins/kumikit/threads.toml` so `kumikit-registry check --base` passes while hiding it from search/install/updates).
- [x] **2. Bundled themes & schema.** Add `sdk/schema/theme.schema.json` and 24 bundled theme files under `themes/` (`kumikit-light`, `kumikit-dark`, plus 22 popular themes: Tokyo Night, Tokyo Night Day, Dracula, Monokai, Catppuccin Mocha/Latte, Rosé Pine/Dawn, Gruvbox Dark/Light, Solarized Dark/Light, Nord, One Dark, GitHub Dark/Light, Everforest Dark, Kanagawa, Ayu Dark, Material Ocean, Night Owl, Palenight), all passing `kumikit theme check --strict themes`.
- [x] **3. Rust crates.** Update `kumikit-theme` and `kumikit theme check` to validate `.json` theme files and directories. Drop `kind = ["theme"]` from `kumikit-assets`, `kumikit-registry`, `kumikit-registry-tool`, `kumikit-shell`, `kumikit-core`, `sdk/schema/ui-plugin-manifest.schema.json`, and update their unit/integration tests.

Update Vitest and Playwright tests.
- [x] **7. Verify.** Run `check-docs.sh`, `check-plugin-names.sh`, `check-no-keys.sh`, `check-templates.sh`, `kumikit theme check --strict themes`, `kumikit-registry check --require-early --base`, `cargo fmt/clippy/test`, `npm run check/test`, `node scripts/bundle.mjs`, and Playwright e2e (`plugins.spec.ts`, `a11y.spec.ts`, `exit-flow.spec.ts`, `panels.spec.ts`, `usage.spec.ts`).
