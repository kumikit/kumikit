# M6 — UI design and usability

- **Goal:** Redesign the client chrome, layout and conversation experience into a minimal, single-click-accessible workspace (Zed-inspired thin bars & docks + Claude-inspired calm chat + Orca-inspired sidebar organization) with resizable left/right sidebars and resizable horizontal/vertical main splits, then iterate on usability issues ([roadmap](../spec/12-roadmap.md#m6--ui-design-and-usability), [06-client](../spec/06-client.md)).
- **Status:** active

## Design principles

1. **Minimal chrome, single-click access.** Thin top bar and bottom status bar host icon buttons with descriptive tooltips (and shortcuts) instead of wide text buttons.
2. **Adjustable workspace geometry.** Left sidebar, right inspector dock, and recursive horizontal/vertical splits in the main area are all resizable via drag handles and persisted in client settings.
3. **Calm reading & writing.** Centered comfortable transcript width, crisp subtle hierarchy for user prompts, assistant prose, tool calls, diffs, and approvals, and an uncluttered floating-style composer.
4. **Orca-inspired left sidebar.** Clear Core → Workspace → Thread hierarchy with collapsible groups, single-click `+` thread creation per workspace, live status indicators, a quick switch between Workspaces tree and flat Active/Recent Threads view, and docked `sidebar.section` plugins.
5. **First-class plugin hosting.** Left sidebar hosts `sidebar.section` plugins; right inspector dock hosts `inspector.tab` plugins (e.g., `kumikit.ui-git`) with a thin tab strip and status-bar quick toggles, using only public slots and `--kk-*` theme tokens.
6. **Zero rule regressions.** Respects `check-ui-rules.mjs` (tokens only, IME-safe inputs), WCAG AA contrast in light and dark themes, keyboard-first navigation, reduced motion, and the ≤ 150 KB UI kernel JS gzip budget.

- Existing tests assert specific accessible names (`Workspaces`, `Open workspaces`, `Open folder…`, `Idle`, `Connected`) and default theme tokens (`--kk-surface-panel` `#15171c`/`#ffffff`, `--kk-text-primary` `#e6e8ee`); preserve all of these.
